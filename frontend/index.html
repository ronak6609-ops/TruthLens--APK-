Process

From upload to verdict in three steps

A transparent analysis pipeline — no black box, no guesswork.

Step 01

Upload Your Media

Drag and drop an image, video, audio clip, or paste a news article. Files are processed within your browser session — nothing is retained.

Step 02

Model Inference

The backend routes your input to the appropriate engine. Visual, audio, and text content are each handled by a specialized detection model.

Step 03

Authenticity Report

A verdict, dual confidence scores, and an analysis summary are returned in seconds — ready to act on or integrate via the API.

Developer API

Integrate in minutes

A clean REST API with consistent JSON responses. No SDK required — just HTTP.

Python 
# Detect AI-generated content
import requests

url = "http://localhost:8000/detect/image"
files = {"file": open("photo.jpg", "rb")}

res = requests.post(url, files=files)
result = res.json()["result"]

# Response
print(result["label"])         # "Real Image" or "AI Generated"
print(result["confidence"])    # 0.0 – 100.0
print(result["fake_score"])    # AI score
print(result["real_score"])    # Real score
